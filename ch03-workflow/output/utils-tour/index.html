Files the LLM picked

This codebase is a utility library for automating repository analysis and documentation generation using large language models, organized around a modular workflow architecture. It features three main subsystems: a filesystem crawler that filters and aggregates source code, an LLM abstraction layer that handles provider routing, caching, and structured response parsing, and a node-based execution framework that orchestrates prompt templates to produce technical overviews. I selected these files because they collectively represent the complete data flow from code ingestion to model interaction and final output generation, capturing the core logic without including dependency manifests or simple barrel exports.
