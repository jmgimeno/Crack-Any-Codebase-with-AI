This codebase implements a "Codebase Knowledge Builder" that transforms a repository into a narrated, HTML-based tutorial using an LLM pipeline. The architecture is defined by a flow of specialized nodes that crawl files, identify abstractions, map relationships, and write sequential chapters. I selected the CLI entry point, the orchestration logic, and the implementation of the core pipeline nodes to reveal the full execution lifecycle.
