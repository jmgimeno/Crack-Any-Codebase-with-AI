Lens: beginner-tutorial · 10 chapters · 20 files analyzed

GNU Make is a build automation tool that reads makefiles, represents targets and prerequisites as an in-memory graph, and rebuilds only the files that need updating. It also expands variables and functions, discovers implicit build rules, runs recipes through shells, and coordinates parallel work across recursive make processes.

This is GNU Make: a C command-line build engine that parses makefiles into a target/dependency graph, expands variables and built-in functions, resolves explicit and implicit rules, and executes recipes with parallel-job coordination. Its central subsystems are makefile parsing, variable/function evaluation, file/dependency/rule data models, timestamp-driven remake traversal, implicit-rule search, filesystem/VPATH lookup, and process/jobserver management. I selected the executable entry point, the concrete implementations of each core phase, and the headers defining the graph and execution-state models, while excluding portability copies, platform-specific variants, and generic utility plumbing.
