Pocket Flow is a minimalist LLM framework that models applications as graphs of reusable nodes and flows. It keeps state in shared dictionaries while supporting sync, async, batch, and nested workflows.

Files the LLM picked

This codebase is PocketFlow, a tiny LLM workflow framework whose core abstractions are Node, Flow, BatchNode, and async variants, with the cookbook serving as the practical documentation of how those primitives compose into agents, workflows, RAG, and batch pipelines. I picked the library core plus representative entry points and concrete implementations for each base class: a research agent for Node/Flow, map-reduce and batch flows for BatchNode/BatchFlow, multi-agent and parallel-batch files for async execution, RAG for nested flows, and a coding agent for Flow-as-node tool loops. I avoided repeated cookbook variants, provider wrappers, tracing, packaging, and other project plumbing so the selected files expose the architecture rather than incidental integrations.
