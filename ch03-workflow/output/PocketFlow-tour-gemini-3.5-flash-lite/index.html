PocketFlow

Lens: beginner-tutorial · 8 chapters · 6 files analyzed

PocketFlow is an ultra-minimalist, 100-line Python framework for orchestrating LLM workflows, agents, and pipelines using graph-based nodes and flows. It enables lightweight, zero-dependency development of complex AI applications through a clear graph abstraction.

Files the LLM picked

This repository is PocketFlow, an extremely minimalist (~100-line) core LLM framework centered around a Directed Graph of Nodes and Flows, accompanied by a rich cookbook of diverse design pattern examples. To understand the core architecture, we must start with the framework's primary source implementation which defines Node, BatchNode, Flow, and asynchronous variants. Alongside the base classes, we select a concrete foundational example from the cookbook, specifically the multi-node research agent pattern, to demonstrate how users subclass nodes, connect transitions via operator overloading, and manage the shared state store.
